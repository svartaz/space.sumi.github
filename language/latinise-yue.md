# latinise cantonese

## initials

each initial hath two variants: high (historically unvoiced) and low (historically voiced).

|            | nasal    | approximant | plain      | aspirate      | fricative |
| ---------: | -------- | ----------- | ---------- | ------------- | --------- |
|       zero |          | (q)         |            |               |           |
|      velar | (q)g [ŋ] |             | k c [k]    | kx ch [kʰ]    | x h       |
| labiovelar |          | (q)w        | kw cw [kʷ] | kxw chw [kʰʷ] |           |
|     dental |          | (q)j        | ts dz [ts] | tsx dzh [tsʰ] | s z       |
|     dental | (q)n     | (q)l        | t d [t]    | tx dh [tʰ]    |           |
|     labial | (q)m     |             | p b [p]    | px bh [pʰ]    | f v       |

## nuclei

|      | front     | front round | centre | back      |
| ---: | --------- | ----------- | ------ | --------- |
| high | i [iː, ɪ] | u [yː]      |        | u [uː, ʊ] |
|  mid | e [ɛː, e] | ø [œː, ɵ]   | y [ɐ]  | o [ɔː, o] |
|  low |           |             | a [aː] |           |

- `i{g`, `u{g`, `e{j`, `o{w`, `ø{j`, and `ø{n` are short and the others are long.
- pronounce long `u` as [uː] after a labiovelar or a labial, otherwise [yː].
- replace `ø` with `r` in ascii-only environments.
