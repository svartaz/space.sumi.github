# latinise japanese

## vowels

- i
- e
- a
- o
- u

## glides

- j
- w

## consonants

|                    | velar | palatal | dental | labial |
| -----------------: | ----- | ------- | ------ | ------ |
| unvoiced obstruent | k     | s       | t      | p, h   |
|   voiced obstruent | c     | z       | d      | b      |
|        approximant | ∅     | j       | r      | w      |
|              nasal | g     |         | n      | m      |

- we use `g` for [c] which originateth from chinese [ŋ]
